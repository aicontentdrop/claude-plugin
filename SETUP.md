# Setup

## From the plugin directory

Inside Claude Code, open the plugin browser with `/plugin`, search for **AI Content Drop**, and install it. The commands appear as `/aicontentdrop:pick-model`, `/aicontentdrop:write-prompt`, `/aicontentdrop:estimate`, `/aicontentdrop:plan-batch` and `/aicontentdrop:drama-outline`.

## From a local clone

Load the plugin for one session without installing anything:

```bash
git clone https://github.com/aicontentdrop/claude-plugin
claude --plugin-dir claude-plugin
```

Check the manifest before loading it:

```bash
claude plugin validate --strict claude-plugin
```

## Credentials

None. The plugin reads only public, credential-free endpoints (the model catalogue and cost estimates) and produces text. Nothing in it asks for or stores an API key, and it never signs you in.

## What the plugin does not do

- It does not generate images, video or audio. Generation happens on aicontentdrop.com after you follow the link each command produces.
- It bundles no MCP server, no hooks and no sub-agents.
- It does not display, compare or change plans. For that, the commands point to <https://aicontentdrop.com/plans>.

## Try it

```text
/aicontentdrop:pick-model a 5-second vertical clip of a matcha latte being poured, product-ad style
/aicontentdrop:write-prompt turn a product photo of a running shoe into a short cinematic clip
/aicontentdrop:estimate 20 shots on kling_3_0, balance 300 credits
/aicontentdrop:plan-batch <paste a shot list>
/aicontentdrop:drama-outline a disowned heiress returns as the new owner of her family's hotel, 3 episodes of 30 seconds
```

## Updating

The plugin follows the repository. Skills under `skills/` are generated by `npm run build:claude-plugin` from the shared source; edit the source, rerun the script, and commit both.
